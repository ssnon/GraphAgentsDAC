# 설계 경계

## 허용된 변경
- 모델이 이미 과학적으로 유효하다고 *판단하고 커밋한* 자문을 다른 새 호출 없이 재사용할 수 있다. 그 평가의 지위는 여전히 MODEL_ADVISORY다.
- 직접 문헌 원문 또는 새 기작 주장 등의 material input 변동 시 NVT/PMI를 새로 실행한다.
- 동일 FRESH Worker가 현재 진행 중이어도 Controller가 새 INFORMED 또는 별도 FRESH Work를 발의할 수 있다. 두 연구의 provenance 분리는 원래 검증기의 책임이며, V3는 이를 덮어쓰지 않는다.
- 새 실행은 기존 Journal 복제 후 `OPERATIONAL_PAUSE` 운영상 영수증으로 분기한다. 원본은 완전 보존한다.

## 명시적 비목표
- 구체적인 SERS charge 가설의 신규성 인증, 실험 성공 보장, Work/Worker의 최소 개수 강제, FRESH에게 기존 연구 노출, 기존 원본 ROOT 덮어쓰기, UNKNOWN 호출을 실패/성공으로 사후 치환, 과학적 HOLD 오버라이드.

## 검증에서 주의할 점
- `OA_PDF_TEXT`도 PDF 텍스트 접근의 기록일 뿐 재현·실험 인증을 뜻하지 않는다.
- 자동 재사용이 기존 학설의 진리 인증은 아니다. 기존 모델 자문을 그대로 인용한다.
- 과학적 중요성의 완전한 기계적 분류기는 아니다. 새로운 직접 근거는 평가하게 하고 단순 메타데이터 중복만 보수적으로 생략한다.
- 최초 V3 판단은 기존 Controller 응답에 새로운 V3 fingerprint가 없으므로 NVT/PMI를 다시 평가할 수 있다. 그 다음부터 데이터가 동일하면 재사용한다.
- 모델 출력이 만든 신규 출처·자산 ID는 원래 Journal의 실재 ID를 검증해야 한다. 가짜 ID 자동 수정 금지.
